# 素材管理客户端

一个面向 macOS 的本地素材管理客户端（0.2.0），参照 Eagle 的三栏交互独立实现。采用 Electron、Fuse.js、file-type、Lucide，并裁剪复用 TagSpaces 的 MIT 文件解析与标签筛选模块。

这是独立项目，与 Eagle 官方无关联，不包含 Eagle 的程序、商业图标或授权逻辑。

## 当前可以做什么

- 导入图片、视频、音频及其他文件；目录导入保留层级。
- 复制原文件并以 SHA-256 核对，识别重复内容，保留来源文件。
- 新建文件夹、多分类整理、添加或移除标签、编辑名称和描述。
- 搜索名称、标签和描述，按类型筛选、按时间/名称/大小排序，调节缩略图大小。
- 图片原图、音视频播放与定位、字体预览；空格预览、方向键切换、Esc 关闭。
- 独立回收站与恢复，关闭和重新打开后保留整理结果。
- 可选择只读接入本机 Eagle `.library`，已有素材的编辑保存在独立覆盖层。
- 从 HTTP(S) 文件直链采集图片、音视频、字体或 PDF，保存来源网页和媒体地址，显示下载失败原因。
- 0–5 星、最近使用、随机浏览、独立智能文件夹、最小尺寸及格式筛选。
- 网格、自适应和列表布局，编辑文件夹名称和层级，应用内拖素材到分类，导出原文件并保留已有同名文件。

## 在本机运行

需要 macOS 和 Node.js 22.12 或更高版本。

```sh
cd client
npm ci
npm start
```

首次运行使用独立空库；点击左侧连接按钮选择 Eagle 素材库。不会自动读取某个作者的私人路径。

图片/视频缩略图会尝试使用 macOS 能力。系统 PATH 中可用的 `ffmpeg`、`ffprobe` 用于补充视频缩略图和音视频信息；也可通过 `FFMPEG_PATH`、`FFPROBE_PATH` 指定本机命令。不提供这些工具时仍保留导入文件，部分缩略图或时长可能不可用。

## 打包与验证

```sh
cd client
npm test
npm run test:ui
npm run test:capture
npm run package
node test/packaged.test.cjs
```

UI 检查使用 ffmpeg 生成合成图片、视频和音频，并在隔离测试库中操作。原 Eagle 库检查为可选项：仅设置 `EAGLE_OPEN_SOURCE` 时执行，所有编辑仍进入测试覆盖层。当前打包目标为 macOS arm64，输出到项目 `dist/`，使用 ad hoc 签名。

## 数据位置与边界

独立索引、新导入副本和缓存在项目 `data/` 中。原 Eagle 元数据与原文件只读取，名称、标签、描述、分类及回收状态写入独立覆盖层。`library.json.bak` 保留上一份独立索引。

构建会生成本机 `workspace.json`，用于让打包应用继续使用当前项目的数据；此配置不在仓库中。迁移项目根目录后需要重新打包。请单独备份数据，保留原素材库。

## 验证与限制

当前版本为 **0.2.0**。数据层 12 项、原有界面 15 项、新采集与整理界面 10 项、打包成品 5 项检查通过；新采集界面另在打包成品复测。原库编辑只写测试覆盖层，前后元数据哈希一致。

网页拖入已接入 HTML、URI 和 DownloadURL 解析，DataTransfer 合约测试通过；真实 Chrome 跨应用试验收到拖拽事件，但最终松开未完成入库，因此**系统跨应用拖放仍待验收**。目前可用工具栏「从链接采集」入口。单个采集文件上限 512 MB、120 秒，不支持播放器网页、登录页、流媒体播放列表、blob/data 图片或 SVG 直链。

完整 Eagle 一比一尚未完成。智能文件夹采用本版独立规则，未转换 Eagle 既有智能规则。颜色筛选、图像/视频区域标注、剪贴板采集、浏览器扩展、插件、密码文件夹、云同步及专业设计格式预览仍缺失；密码文件夹不接入。PDF 可采集和导出，但暂无内置预览。

没有逐一验证全部格式、编解码、数 GB 文件或十万级素材库。未提供经过 Developer ID 签名和公证的安装包，当前仓库发布源码。
